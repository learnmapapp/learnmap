Go (often called Golang) is a programming language created at Google in 2009. Docker, Kubernetes, Terraform and a large part of the internet's infrastructure are written in it.

Its whole personality is **simplicity**. Go has very few features on purpose: one kind of loop, no classes, no exceptions. That makes Go code look alike no matter who wrote it, which is a big deal when a team of hundreds works on the same code.

```go title=main.go
package main

import "fmt"

func main() {
    fmt.Println("Hello, Go!")
}
```

```repl shell
> go run main.go
Hello, Go!
```

A few things Go is known for:

- **Fast builds.** Even large programs compile in seconds, into a single file you can copy to a server and run.
- **Garbage collection.** You don't free memory yourself.
- **Goroutines.** Running thousands of things at once is built into the language, and cheap.
- **A great standard library.** An HTTP server, JSON, testing and formatting all come in the box.

## What you'll find on this map

- **Basics**: variables, types, functions, loops and decisions.
- **Data**: slices, maps, structs and pointers.
- **Interfaces and generics**: how Go shares behaviour between types.
- **Errors**: Go has no exceptions. Errors are ordinary values you check.
- **Concurrency**: goroutines and channels, Go's most famous feature.
- **Tools and the web**: modules, tests, JSON and an HTTP server.
