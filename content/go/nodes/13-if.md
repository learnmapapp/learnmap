`if` in Go has **no brackets** around the condition, and the **braces are required**, even for one line:

```go title=main.go
package main

import "fmt"

func main() {
    temp := 31

    if temp > 30 {
        fmt.Println("Hot!")
    } else if temp < 5 {
        fmt.Println("Cold!")
    } else {
        fmt.Println("Nice.")
    }
}
```

The `else` has to be on the same line as the closing brace `}`. That's not style, it's how Go's parser works.

## The short statement

`if` can start with a small statement, separated by a semicolon. A variable declared there only exists inside the `if` and its `else` branches:

```go
if n, err := strconv.Atoi(input); err != nil {
    fmt.Println("not a number:", input)
} else {
    fmt.Println("doubled:", n*2)
}
// n and err don't exist here
```

You'll see this pattern all the time with errors and map lookups, because it keeps temporary variables out of the way.

## No ternary operator

Go has no `cond ? a : b`. You write an `if` instead:

```go
label := "odd"
if n%2 == 0 {
    label = "even"
}
```

Conditions combine with `&&` (and), `||` (or) and `!` (not), and must be real `bool`s. `if count {` doesn't compile when `count` is a number.

```compare python
if temp > 30:
    print("Hot!")
```

```compare javascript
if (temp > 30) { console.log("Hot!"); }
```

```compare java
if (temp > 30) System.out.println("Hot!");
```

```compare rust
if temp > 30 { println!("Hot!"); }
```
