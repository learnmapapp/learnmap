title: If expressions
icon: "🚦"

requires: [booleans, integers]
summary: if works as a statement and as an expression that returns a value.
---
`if` looks the way you'd expect:

```zig
if (temperature > 30) {
    std.debug.print("Hot!\n", .{});
} else if (temperature < 0) {
    std.debug.print("Freezing!\n", .{});
} else {
    std.debug.print("Nice.\n", .{});
}
```

The twist is that `if` is also an **expression**: it produces a value. That replaces the `? :` ternary operator from other languages, which Zig doesn't have:

```zig title=traffic.zig
const std = @import("std");

pub fn main() void {
    const light = "red";
    const speed: u8 = if (std.mem.eql(u8, light, "green")) 50 else 0;
    std.debug.print("speed: {d}\n", .{speed});
}
```

When `if` gives a value, the `else` is required. Otherwise, what would `speed` be when the light isn't green?

You'll often use it to keep a `const` instead of reaching for a `var`:

```zig
// Instead of this...
var label: []const u8 = "odd";
if (n % 2 == 0) label = "even";

// ...write this:
const label = if (n % 2 == 0) "even" else "odd";
```

```compare python
label = "even" if n % 2 == 0 else "odd"
```

```compare javascript
const label = n % 2 === 0 ? "even" : "odd";
```

```compare rust
let label = if n % 2 == 0 { "even" } else { "odd" };
```

```exercise
goal: Zig has no ternary operator. Rewrite this with an if expression.
code: |-
  fn fee(age: u8) u32 {
      return age < 12 ? 0 : 15;
  }
checks:
  - notMatch: '\?'
    message: "Zig has no ? : operator."
  - match: 'return\s+if\s*\(\s*age\s*<\s*12\s*\)\s*0\s+else\s+15'
    message: Write it as if (condition) value else other_value.
solution: |-
  fn fee(age: u8) u32 {
      return if (age < 12) 0 else 15;
  }
```

```quiz
question: Why must `const x = if (ok) 1;` have an `else`?
options:
  - Style rules require every if to have an else.
  - Without it, x would have no value when ok is false.
  - Only if statements can omit the else; if expressions can't be assigned at all.
answer: 1
explain: An if expression must produce a value on every path, so the else branch is required.
```
