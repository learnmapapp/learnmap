Python is a general-purpose language for automating chores, exploring data, building services, and turning ideas into working programs. You can start with a single file and grow into a package with tests.

```python
name = "Ada"
print(f"Hello, {name}!")
```

The [[interpreter]] runs your program. Python checks many operations when they execute: adding a number to a string raises an error instead of silently choosing what you meant. Readability matters too: indentation defines blocks, and functions and variables usually use `snake_case` names.

## Pick a path

Start with [running Python](node:running-python), then learn values, decisions, loops, and functions. Other branches cover collections, file automation, classes, and testing. These lessons target **Python 3.11 or newer** and use the standard library unless a lesson explicitly discusses installing a dependency.
