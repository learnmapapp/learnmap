Here's a plain class for a book, written by hand:

```python
class Book:
    def __init__(self, title, author, pages):
        self.title = title
        self.author = author
        self.pages = pages

    def __repr__(self):
        return f"Book({self.title!r}, {self.author!r}, {self.pages})"

    def __eq__(self, other):
        return (self.title, self.author, self.pages) == (
            other.title, other.author, other.pages)
```

Every field is typed three times, and adding a field means editing three methods. Now the [[dataclass]] version:

```python
from dataclasses import dataclass

@dataclass
class Book:
    title: str
    author: str
    pages: int
```

Same behaviour. The `@dataclass` [[decorator]] reads the field list and writes `__init__`, `__repr__` and `__eq__` for you:

```repl
> b = Book("Dune", "Frank Herbert", 412)
> b
Book(title='Dune', author='Frank Herbert', pages=412)
> b == Book("Dune", "Frank Herbert", 412)
True
```

The `: str` and `: int` are [type hints](node:type-hints). Dataclasses need them to find the fields, but Python doesn't enforce them at runtime.

## Handy options

```python
@dataclass(frozen=True)     # instances can't be changed after creation
class Point:
    x: float
    y: float = 0.0          # fields can have defaults
```

Frozen instances raise an error if you try `p.x = 5`, and they can be used as dictionary keys.

## The list default

Just like [function defaults](node:function-arguments), a mutable default would be shared between instances. Dataclasses refuse it outright:

```python
@dataclass
class Course:
    lessons: list[str] = []
```

```text
ValueError: mutable default <class 'list'> for field lessons is not allowed: use default_factory
```

The error tells you the fix: `field(default_factory=list)` calls `list()` to build a fresh one for every instance.

```compare kotlin
data class Book(val title: String, val author: String, val pages: Int)
```

```compare java
record Book(String title, String author, int pages) {}
```

```exercise
goal: "Dataclasses reject a `[]` default. Give each `Course` its own fresh `lessons` list."
lang: python
code: |
  from dataclasses import dataclass, field

  @dataclass
  class Course:
      title: str
      lessons: list[str] = []

  print(Course("Python"))
checks:
  - match: 'lessons:\s*list\[str\]\s*=\s*field\(\s*default_factory\s*=\s*list\s*\)'
    message: Replace [] with field(default_factory=list).
hint: field is already imported; it takes a default_factory.
solution: |
  from dataclasses import dataclass, field

  @dataclass
  class Course:
      title: str
      lessons: list[str] = field(default_factory=list)

  print(Course("Python"))
```
