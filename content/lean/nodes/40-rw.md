`rw [h]` uses an equation `h : a = b` to replace `a` with `b` in the goal. It's the tactic version of "substitute equals for equals".

```lean title=Rewrite.lean
theorem example1 (a b : Nat) (h : a = b) : a + 1 = b + 1 := by
  rw [h]
```

Before `rw`, the goal is `a + 1 = b + 1`. After replacing `a` with `b`, it's `b + 1 = b + 1`, and `rw` closes it with `rfl` automatically.

## Rewriting with theorems

You can rewrite with any theorem that states an equation, including Lean's library:

```lean
theorem example2 (a b : Nat) : a + b + 0 = b + a := by
  rw [Nat.add_zero]    -- goal: a + b = b + a
  rw [Nat.add_comm]    -- goal: b + a = b + a, closed
```

`Nat.add_comm : a + b = b + a` is a theorem with parameters; `rw` works out which `a` and `b` to use from the goal.

## Several at once, backwards, and elsewhere

```lean
theorem example3 (a b c : Nat) (h1 : a = b) (h2 : b = c) : a = c := by
  rw [h1, h2]          -- one rw, several steps

theorem example4 (a b : Nat) (h : a = b) (hb : b > 5) : a > 5 := by
  rw [← h] at hb       -- replace b with a, in hb
  exact hb
```

| Form | Effect |
| --- | --- |
| `rw [h]` | replace the left side of `h` with the right side, in the goal |
| `rw [← h]` | right side with left side |
| `rw [h1, h2]` | one after the other |
| `rw [h] at h'` | rewrite in hypothesis `h'` instead |

```warn
rw rewrites every match of the first pattern it finds. If it picks the wrong one, give the arguments explicitly, as in rw [Nat.add_comm a b].
```

```exercise
goal: "Use the hypothesis `h` to rewrite the goal: add `rw [h]`."
code: |
  theorem use_h (x y : Nat) (h : x = y + 2) : x * 3 = (y + 2) * 3 := by
    sorry
checks:
  - notMatch: 'sorry'
    message: "Replace sorry."
  - match: 'rw\s*\[\s*h\s*\]'
    message: "Write rw [h]"
solution: |
  theorem use_h (x y : Nat) (h : x = y + 2) : x * 3 = (y + 2) * 3 := by
    rw [h]
```
