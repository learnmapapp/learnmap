**Statement form**: do one thing or another. Python programmers will recognize everything here, except that it's `elif`, and the conditions must be real `bool`s:

```nim title=weather.nim
let celsius = 31

if celsius >= 30:
  echo "Hot! Stay in the shade."
elif celsius >= 18:
  echo "Lovely weather."
else:
  echo "Bring a jacket."
```

Indentation marks the blocks; two spaces is the Nim convention. Conditions combine with `and`, `or` and `not`, written as words.

**Expression form**: *choose a value*. In Nim, `if` can sit on the right side of `=`:

```nim
let advice = if celsius >= 30: "shade" else: "sun"
let fee = if age < 12: 0
          elif age >= 65: 5
          else: 10
```

That's Nim's answer to the ternary operator `?:`. The rules for the expression form:

1. There must be an `else`. Otherwise, what would the value be when no condition matches?
2. Every branch must produce the same type. `if ok: 1 else: "none"` won't compile.

**Only `bool` counts as a condition.** Python lets you write `if items:` or `if count:`. Nim doesn't, and asks you to say what you mean:

```nim
if count:          # Error: type mismatch, int is not bool
if count > 0:      # fine
if name.len > 0:   # instead of `if name:`
```

It's slightly more typing, and it means `if` never surprises you with "empty counts as false" rules.

```compare python
advice = "shade" if celsius >= 30 else "sun"
```

```compare javascript
const advice = celsius >= 30 ? "shade" : "sun";
```

```compare rust
let advice = if celsius >= 30 { "shade" } else { "sun" };
```

```exercise
goal: "Replace the four-line if statement with a single `let` using an if expression."
code: |-
  let points = 72
  var verdict: string
  if points >= 50:
    verdict = "pass"
  else:
    verdict = "fail"
  echo verdict
checks:
  - match: 'let\s+verdict\s*=\s*if\s+points\s*>=\s*50\s*:\s*"pass"\s+else\s*:\s*"fail"'
    message: 'Write let verdict = if points >= 50: "pass" else: "fail"'
  - notMatch: 'var\s+verdict'
    message: Remove the var declaration.
solution: |-
  let points = 72
  let verdict = if points >= 50: "pass" else: "fail"
  echo verdict
```

```quiz
question: "Why doesn't `let x = if ok: 1` compile?"
options:
  - if can't be used as an expression.
  - The expression form needs an else, so there's always a value.
  - ok must be written in parentheses.
answer: 1
explain: Without else, x would have no value when ok is false.
```
