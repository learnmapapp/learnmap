Lua strings are sequences of **bytes**, not characters. Most source files and terminals use UTF-8, where ASCII characters take one byte, "é" takes two, and most emoji take four. `#`, `string.sub`, `string.upper` and patterns all work on bytes.

For a lot of code that's fine, for example when you're just passing text along, comparing it, or splitting on commas and spaces. When you need to count or walk *characters* (Unicode calls them **code points**), Lua 5.4 has the `utf8` library:

```lua
local word = "naïve"

print(#word)            -- 6 bytes
print(utf8.len(word))   -- 5 characters

for _, code in utf8.codes(word) do
  io.write(utf8.char(code), " ")
end
-- n a ï v e
```

| Function | Does |
| --- | --- |
| `utf8.len(s)` | counts characters. Returns `nil` plus a position if the string isn't valid UTF-8. |
| `utf8.codes(s)` | iterates: byte position and code point number |
| `utf8.char(n, ...)` | builds a string from code points: `utf8.char(9731)` is ☃ |
| `utf8.codepoint(s, i)` | the code point at byte position `i` |
| `utf8.offset(s, n)` | the byte position where character `n` starts |
| `utf8.charpattern` | a pattern that matches one UTF-8 character |

`utf8.offset` makes "first three characters" possible:

```lua
local s = "über cool"
print(s:sub(1, utf8.offset(s, 4) - 1))   -- übe
```

And `utf8.charpattern` works with `gmatch` to split a string into characters:

```lua
for ch in ("añb"):gmatch(utf8.charpattern) do print(ch) end
```

**What the library doesn't do:** upper and lower case for non-ASCII letters, sorting by language rules, or combining characters (an emoji with a skin tone counts as two code points). For those, reach for a library like `luautf8`, or the host program's tools.

```compare python
len("naïve")      # 5: Python strings are code points
len("naïve".encode())   # 6 bytes
```

```compare javascript
"naïve".length;        // 5, but counts UTF-16 units, so "👋".length is 2
[..."👋"].length;      // 1
```

```compare rust
"naïve".len();              // 6 bytes, like Lua
"naïve".chars().count();    // 5
```
