A traffic light, written as code:

```mojo title=light.mojo
def main():
    var light = "amber"
    var seconds_left = 2

    if light == "green":
        print("Go")
    elif light == "amber" and seconds_left > 3:
        print("Go, carefully")
    elif light == "amber":
        print("Stop if you safely can")
    else:
        print("Stop")
```

```repl shell
> mojo run light.mojo
Stop if you safely can
```

Mojo checks the conditions from top to bottom and runs **only the first** block whose condition is true. The second `elif` never sees amber with 3+ seconds left, because the one above it already caught that case. Order matters: put specific cases before general ones.

The shape is pure Python: a colon at the end of each condition line, and an indented block below it. There are no braces and no parentheses needed around the condition. Indentation isn't decoration here; it's how Mojo knows which lines belong to the block.

**Conditional expressions** pick between two values in a single line:

```mojo
var label = "adult" if age >= 18 else "minor"
```

Both values must have the same type. `"adult" if ok else 0` doesn't compile, because `label` would be a `String` sometimes and an `Int` other times.

**Variables and branches.** A variable declared *inside* a block only exists inside that block. If you need the result afterwards, declare the variable before the `if`:

```mojo
var fee: Int
if age < 12:
    fee = 0
else:
    fee = 8
print(fee)   # fine: every path assigns fee
```

The compiler checks that every path assigns `fee` before it's read. Delete the `else` and you'll get an error instead of a mystery value.

```compare python
label = "adult" if age >= 18 else "minor"   # identical
```

```compare javascript
const label = age >= 18 ? "adult" : "minor";
```

```compare rust
let label = if age >= 18 { "adult" } else { "minor" };
```

```exercise
goal: "The cheapest ticket is never printed for 70-year-olds: the first condition catches them. Swap the order so the `age >= 65` check comes first."
code: |-
  def main():
      var age = 70
      if age >= 18:
          print("Adult ticket")
      elif age >= 65:
          print("Senior ticket")
checks:
  - match: 'if\s+age\s*>=\s*65\s*:\s*\n\s+print\("Senior ticket"\)\s*\n\s*elif\s+age\s*>=\s*18\s*:'
    message: Check age >= 65 in the if, and age >= 18 in the elif.
solution: |-
  def main():
      var age = 70
      if age >= 65:
          print("Senior ticket")
      elif age >= 18:
          print("Adult ticket")
```
