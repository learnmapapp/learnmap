---
title: Garbage collection
icon: "🧹"
branch: tooling
requires: [store, profiles]
summary: Clean up the store without breaking anything.
---
Nix never overwrites or deletes on its own, so `/nix/store` keeps growing. The garbage collector cleans up.

```shell
$ nix-collect-garbage
deleting '/nix/store/…-python3-3.11.9'
2.4 GiB freed
```

It only deletes paths that nothing points to. The things that keep a path alive are called **GC roots**: your profiles and their generations, `result` symlinks from builds, and running NixOS systems.

Old generations keep old packages alive. To delete those too:

```shell
$ nix-collect-garbage --delete-older-than 14d
$ sudo nix-collect-garbage -d     # all old generations, including the system's
```

After `-d` you can't roll back to those generations anymore.

Two more space savers:

```shell
$ nix store optimise           # hard-link identical files
$ nix path-info -Sh nixpkgs#firefox   # how big is it, with dependencies?
```

On NixOS, let it happen automatically:

```nix
nix.gc = {
  automatic = true;
  dates = "weekly";
  options = "--delete-older-than 30d";
};
```

  - Your profile is a GC root that points to it.
  - Packages are never deleted.
answer: 1
explain: Anything reachable from a GC root, like a profile generation, is kept.
